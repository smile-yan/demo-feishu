第 1 次确认（共 2 次）：用手机飞书扫码，或在本机浏览器打开链接。 飞书页面会让你选择「创建飞书应用」或「使用已有应用」，无论选哪个， 本演示都会拿到对应的 App ID 与 App Secret（凭证只保存在服务端）。 这一步只产生应用凭证；你的用户 token 在第 2 步授权时发放。
真的只想确认一次？在 backend/.env 里填好 LARK_APP_ID / LARK_APP_SECRET，本步会自动跳过。
